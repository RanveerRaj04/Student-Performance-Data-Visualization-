# 📊 Student Performance Data Visualization

A Python-based data analysis and visualization project that explores **student performance data** using **Pandas** and **Matplotlib**.

The project uses a Jupyter Notebook (`project.ipynb`) to analyze the dataset and create different visualizations for understanding student performance, trends, distributions, and relationships between variables.

## 🚀 Project Overview

This project works with student performance data containing information such as:

* Student ID
* Attendance
* Study Hours
* Sleep Hours
* Subject Marks
* Overall Performance

The data is analyzed using Pandas and visualized using Matplotlib.

## 🛠️ Technologies Used

* **Python**
* **Pandas**
* **Matplotlib**
* **Jupyter Notebook**

## 📈 Visualizations

The notebook includes:

* 📊 **Bar Charts** - Comparing student and subject performance
* 📈 **Line Charts** - Analyzing trends and comparisons
* 📉 **Histograms** - Understanding data distributions
* 🔵 **Scatter Plots** - Exploring relationships between variables
* 🔲 **Subplots** - Displaying multiple visualizations together
* 🎨 **Heatmap-Style Visualization** - Visualizing relationships between variables using `imshow()`

## ▶️ How to Run

### 1. Clone the repository

```bash
git clone https://github.com/your-username/Student-Performance-Data-Visualization.git
```

### 2. Navigate to the project directory

```bash
cd Student-Performance-Data-Visualization
```

### 3. Install the required libraries

```bash
pip install pandas matplotlib jupyter
```

### 4. Open the notebook

```bash
jupyter notebook project.ipynb
```

You can also open `project.ipynb` directly using **Jupyter Notebook, JupyterLab, or VS Code**.
